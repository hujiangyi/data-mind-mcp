# 故障排查

## MCP 客户端立即退出

检查 `DATAMIND_CREDENTIAL`、`DATAMIND_MASTER_KEY` 和
`DATAMIND_API_BASE` 是否全部存在。凭据对必须来自同一个 Go 服务，
不能混用不同用户的配置。

## 提示必须先完成首次改密

如果配置页面提示账号仍需改密，请先登录 DataMind Go 网站。全新管理员
使用临时初始密码 `123456`，管理员创建或重置的账号也使用该密码；普通
用户自助注册账号同样必须完成首次改密。设置 8～16 位正式密码后，再重新
打开配置链接。

## 查询工具没有显示

MCP 客户端会根据凭据 scope 过滤工具。请检查 Go 服务签发的 scope。
不要在客户端配置中自行添加管理员 scope，最终权限仍由 Go 服务判断。

## 云端 AI 不可用

MCP 客户端只负责连接 Go 服务，不保存也不管理 DataMind Cloud API Key。
请联系 Go 服务管理员检查服务端的云端 profile、会员状态、额度和队列等级。

## 没有收到 MCP 安装邮件

先确认注册时填写的邮箱地址拼写正确，邮箱当前可以正常收信，并检查垃圾
邮件、广告邮件、隔离区以及企业邮箱网关。不同邮箱服务商的拦截策略可能
不同，可以改用另一个真实且可接收邮件的邮箱重新注册或重试。

如果多个有效邮箱都没有收到邮件，再联系 Go 服务管理员，并提供注册时间
和脱敏后的邮箱地址。不要把 MCP 凭据复制到公开 Issue 或聊天消息中。
